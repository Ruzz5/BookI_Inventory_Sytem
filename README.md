# BookI_Inventory_Sytem
# The system follows a simple and user-friendly interface flow:

Login Page
Users log in using their credentials
Option to create a new account if not registered
Registration Page
Users input their details to create an account
Redirected back to login after successful registration
Dashboard
Displays book inventory
Shows weekly income summary
CRUD Operations
Create: Add new book records
Read: View all books in a table
Update: Edit existing book details
Delete: Remove records with a confirmation popup
Delete Confirmation
A confirmation message appears before deleting data to prevent accidental removal
